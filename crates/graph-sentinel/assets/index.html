      Scope

      What it does, and what it does not.

      Does

      • Catches a deployment that has stopped while graph-node calls it healthy, by asking the chain whether events are waiting for it.
      • Tells a stalled chain from a stalled deployment, and a quiet contract from a frozen one.
      • Counts the deployments you were paid to serve each day and replays the oracle's rule over them.
      • Reads eligibility straight from the RewardsEligibilityOracle contract, and ranks deployments worth adding.

      Does not

      • See addresses created by templates, so a template-heavy deployment can only be called "not moving", never "frozen".
      • See latency or freshness as the gateway measured them. Receipts make every REO count an upper bound.
      • Write to any database, allocate, or sign anything. A restart happens only if you switch it on.
      • Ask for a login. Keep it on loopback or behind your own proxy.
